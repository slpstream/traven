# Traven naming, and why

As a name for an editor, "Traven" stands alone. It means nothing obvious to a developer scanning GitHub, which means it doesn't oversell or undersell itself before someone clicks through. It has a quiet literary quality without being pretentious about it. 

It doesn't explain itself. It rewards the curious and doesn't need the approval of the incurious.

If anyone does know the reference — B. Traven, the author of *The Treasure of the Sierra Madre*, one of the most successfully anonymous writers of the twentieth century, a man whose true identity was never conclusively established despite decades of investigation — then they'll appreciate the joke immediately.

Traven was an anonymous author who wrote about ordinary people fighting systems that would grind them down, whose manuscripts arrived at publishers without a return address, who communicated through intermediaries, who built a body of work that outlasted every attempt to attach a name to it.
For a WYSIWYM editor that will ship inside a CMS, MIT licensed, built by someone who understands what ownership actually means in practice — that's about as apt a namesake as you could find.

The name Traven has a philosophy embedded in it: B. Traven spent his entire career proving that the work outlasts the author, that anonymity is not absence, that you can build something real and meaningful and then walk away from it completely and it still exists on its own terms.

For a tool we intend to build well and then hand to the commons, there is no better patron saint.

### Runner-up name: Skribent

Skribent is a worthy runner-up. Clean, functional, immediately legible — it means "writer" in the Scandinavian languages, which fits the tool perfectly and nods to that tradition of plain, honest design. No mystery to it, but no pretension either. A developer scanning GitHub knows exactly what it is before clicking.

It is a name that competes with EasyMDE and Toast UI on the same shelf, and it could be the right name for a project that wants to be found, understood immediately, adopted widely.
