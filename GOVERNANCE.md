# Traven Governance

This document states what Traven is and how it will be run. It exists so that anyone building on Traven can know exactly what they are dealing with.

**What Traven is**: Traven is a free, open-source tool. It was built to fill a gap for a full-featured, framework-agnostic Markdown editor in the browser with WYSIWYG/WYSIWYM. It is licensed under MIT. You can drop it in anywhere you need to edit Markdown as rich text and it just works. There are lots of ways to customize how the editor looks and behaves with toolbar configurations, themes, typefaces, and the ability to extend with custom shortcodes to fill pretty much any need you can imagine from a powerful editor. It works great on long documents and is not brittle. 

**What Traven is not**: Traven is not a paid product, SaaS, startup, platform, or service requiring API keys.

**The license will not change**: Traven is MIT licensed and will remain under the MIT license forever. There will be no license switch to BSL, AGPL, or anything else designed to restrict commercial use after the fact. If you build something with Traven today, the terms under which you are using it will not change tomorrow.

**Forks are welcome**: The MIT license already guarantees this legally, but it is worth stating plainly that forks are not just tolerated—they are welcomed and supported. If you want to take Traven in a different direction (add a paid layer, integrate it into a commercial product, or build something entirely different on top of it), you are free to do so. That is what the license is for. A fork that monetizes Traven does not diminish the original, which will always stay free and open to anyone. If you want to call your fork something "Traven"-related, please be cool about it and check in first so users won't be confused about which is what.

**Donations and sponsorship**: Traven is free. Sponsorship or donations are optional, transparent, and do not create any class of user with privileged access, influence over direction, or features unavailable to others. It is just a way to say thank you, if someone wants to.

### What will never happen

To be explicit about the failure modes this document is designed to prevent:

- Traven will not introduce a registration requirement.
- Traven will not require an API key for use.
- Traven will not add telemetry or usage tracking of any kind.
- The core tool will not be paywalled, in whole or in part. Traven will remain free, open, and honest about what it is. 

**If the maintainer disappears**: Open-source projects sometimes outlive their maintainers' interest or availability. If that happens with Traven: The MIT license means the last released version remains fully usable, forkable, and redistributable by anyone, forever, and nothing is ever locked away. If maintenance is handed to another party, this governance document transfers with it as a condition of the handoff.

---

*This document is intended to be read by a developer who is deciding whether to build something on Traven. If you are that developer: the answer to your actual question is yes, you can trust it.*
